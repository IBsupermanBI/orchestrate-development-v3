# Timesheet

Один глобальный скилл для локальной телеметрии Codex:

- `$timesheet report` — Markdown за последние 7 дней по текущему проекту.
- `$timesheet save` — JSON за последние 7 дней в `.scratch/timesheets/` проекта.
- `$timesheet current` — краткий отчёт по текущей задаче за всё её время, включая связанные дочерние задачи и субагентов.

Период и фильтры можно уточнять обычным текстом. Хук телеметрии устанавливается отдельно. Скилл работает с уже собранными журналами, без сети и дополнительных моделей. Неполные данные отмечаются явно; расчётные кредиты не равны проценту расхода лимитов подписки. См. [источник тарифов и ограничения](references/credits.md).

Установка: `python install.py --user` показывает план, `python install.py --user --apply` устанавливает глобально. Node.js 22+, Python 3.11+ для установщика. Для другого дома используйте `--home PATH`; для проекта — `--project PATH`. Все исполняемые зависимости входят в пакет; npm не требуется. MIT, IBsupermanBI.

Отчёт содержит покрытие данных, раздельные reasoning efforts, цели/запросы и их собственные интервалы. `--include-text` включает сохранённые выдержки запросов и результатов по явному запросу пользователя. Автоматический request ID не является распознанной бизнес-целью; завершённый ответ не доказывает достижения цели. Кредиты и токены по целям распределяются только для аддитивного usage, с раздельными scope.
